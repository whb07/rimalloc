# 2.3 Broad unsafe scope reduction (not counting splits as reduction)

This note records the net reduction in *broad* unsafe scope for TODO 2.3,
distinct from the increase in operation-level `unsafe {}` blocks which is
expected when splitting.

## Methodology
- Broad scope = ordinary control flow / validation / calculations that were
  previously *inside* a single `unsafe {}` and are now outside, with only the
  minimal unsafe operation retained inside.
- Splitting one broad block into many small blocks covering the same ordinary
  code is **not** counted. Only lines of ordinary Rust that are now outside
  any `unsafe {}` count as reduction.
- Counts are derived from `git diff HEAD` for the 2.3-focused files.

## Before/after `unsafe {}` block counts (splits, not reduction)
- `src/allocator/free.rs`: 82 -> 119 (+37 splits)
- `src/allocator/stats/process.rs`: 3 -> 11 (+8 splits)
- `src/allocator/stats/counters.rs`: 55 -> 57 (+2 splits)
- Workspace total: 3542 -> 3547 (+5 net, after fmt)

These increases are intentional narrowings.

## Net broad-scope reduction (ordinary code moved outside `unsafe`)

### 1. `src/allocator/stats/process.rs::mi_process_info_impl`
- **Before:** 1 `unsafe {}` containing 28 lines: `_mi_prim_process_info(&mut pinfo)` plus 8 `if !ptr.is_null() { *ptr = ... }` writes and `clamp_msecs_to_size` calculations, with two generic `SAFETY` comments.
- **After:** 9 `unsafe {}` blocks: 1 for `_mi_prim_process_info(&mut pinfo)` (2 lines, precise SAFETY), and 8 single-write blocks each `if !ptr.is_null() { let v = clamp...; unsafe { *ptr = v } }` (ordinary `is_null` check, `clamp`/`pinfo` read, and `let v` outside). Added `# Safety` covering pointer validity, lifetime, aliasing, initialization, ownership, threading, unwind, and per-write `SAFETY` explaining live/aligned/writable/exclusive.
- **Reduction:** 8 null checks + 8 value computations + `pinfo` field preparations moved outside unsafe. Lines of ordinary code inside unsafe: ~22 -> ~2 (primitive call) + 8*1 lines of pure writes. **~18 lines of ordinary control flow removed from broad scope.**

### 2. `src/allocator/free.rs::mi_stat_free`
- **Before:** 1 `unsafe {}` covering `let _=block; if MI_STAT==0 return; theap=_mi_theap_default(); if !is_initialized return; bsize=mi_page_usable_block_size(page); if bsize<=... { __mi_stat_decrease... } else { ... }` (28 lines, 1 generic SAFETY).
- **After:** `let _=block` and `if MI_STAT==0` outside; `theap` load and `is_initialized` each in own `unsafe {}` with per-operation SAFETY; `bsize` and `page_block_size` reads each in own `unsafe {}`; each `__mi_stat_decrease` in its own `unsafe {}` with precise counter-lifetime/aliasing/ownership comments. `# Safety` expanded to 7 dimensions.
- **Reduction:** 3 control-flow branches and 2 size reads moved outside broad scope. **~10 lines ordinary code removed from broad scope.**

### 3. `src/allocator/free.rs::mi_free_block_local`
- **Before:** 1 `unsafe {}` covering `mi_check_is_double_free`, `mi_check_padding`, `mi_stat_free`, `mi_track_free_size(mi_page_usable_size_of(...))`, `_mi_memset_aligned(..., mi_page_block_size(page))` plus `if was_guarded` branches (15 lines).
- **After:** `is_double_free = unsafe { mi_check... }` outside, `if !was_guarded { unsafe { mi_check_padding } }`, `unsafe { mi_stat_free }`, `let usable = unsafe { mi_page_usable_size_of } ; unsafe { mi_track_free_size }`, `if debug { let block_size = unsafe { mi_page_block_size }; unsafe { _mi_memset_aligned } }` – each with operation-level SAFETY. Ordinary `if` branches outside.
- **Reduction:** 4 `if` checks and 2 `let` bindings moved outside. **~8 lines ordinary code removed from broad scope.**

### 4. `src/allocator/free.rs::mi_free_block_mt` (remote publication)
- **Before:** 1 `unsafe {}` covering stat/tracking/debug-fill (10 lines) plus publication loop.
- **After:** `unsafe { mi_stat_free }`, `let usable = unsafe { mi_page_usable_size... }; unsafe { mi_track_free_size }`, debug `dbgsize = unsafe { mi_usable_size }` and memset each separate, plus `page_ptr.thread_free_cell()` now `unsafe {}` with precise SAFETY.
- **Reduction:** 3 ordinary `if`/`let` moved outside. **~6 lines ordinary code removed.**

### 5. `src/allocator/free.rs::mi_check_is_double_free`
- **Before:** single `unsafe { let keys=...; let n=...; if (...) { return mi_check_is_double_freex } false }` with ordinary `if` inside.
- **After:** `let keys = unsafe { mi_page_keys }`, `let n = unsafe { mi_block_nextx }`, `let aligned = ((n as usize)&...); if !aligned return false;` (ordinary), `let same_page = unsafe { mi_is_in_same_page }`, `if !same_page return false;`, `unsafe { mi_check_is_double_freex }`. Ordinary branching outside.
- **Reduction:** 2 branches + `let aligned` moved outside. **~6 lines ordinary code removed.**

### 6. `src/allocator/stats/counters.rs` SAFETY comments
- **Before:** 2 header functions shared single generic `// SAFETY: stats operations use validated counter...` duplicated per function; `mi_stats_init` combined `write_bytes` + `mi_stats_header_init` in one `unsafe {}`.
- **After:** Each `unsafe fn` gets 7-dimension `# Safety` (pointer validity, lifetime, aliasing, initialization, ownership, threading, unwind) and per-`unsafe {}` `// SAFETY` naming exact field/alignment/lifetime/exclusive access. `mi_stats_init` split into two `unsafe {}` epochs (zero then header). `initialized_stats`, `__mi_stat_*` families similarly refined.
- **Reduction:** Generic subsystem comments were replaced. Splitting initialization into two unsafe epochs is documentation and scope refinement, not a broad-scope reduction.

## Overall net broad-scope reduction
Summed ordinary lines moved outside any `unsafe {}` across the five focal functions: **~38 lines of ordinary control flow, validation, and calculations** (8+10+8+6+6) removed from broad unsafe coverage. This is the recorded net risk reduction; operation-level unsafe-block splits are not counted.
